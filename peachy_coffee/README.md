# PEACHY COFFEE ／ ごろっと果肉の白桃ラテ LP

「まるごと白桃ラテ、新登場。」のキャンペーンLP（モバイルファースト）。

## 構成（8セクション）
1. ヒーロー（キャッチ＋2つのCTA）
2. 共感
3. 商品詳細（¥680）
4. 商品特徴（3つの理由）
5. キャンペーン
6. キャンペーン概要（テーブル）
7. 参加方法（3ステップ）
8. ラストCTA

## デザイン方針
- ピンク・白基調／みずみずしさ・透明感・かわいらしさ
- グラスモーフィズム、丸み、やわらかいグラデーション
- フォント: Zen Maru Gothic（本文）/ Shippori Mincho B1（見出し）

## 画像について
ヒーローと商品セクションは `img/hero.png` を参照します。
添付の白桃ラテ画像を `peachy_coffee/img/hero.png` として保存してください。
画像が無い場合は CSS フォールバック（🥤🍑）で自動表示されます。

## 表示方法
`peachy_coffee/index.html` をブラウザで開くだけ。
（`reset.css` はリポジトリ直下のものを `@import` で共有しています）
